SoniXense typefaces
===================
Manrope        — display: wordmark support, headlines, slide titles, names.
Inter          — text: body copy, UI, long-form.
IBM Plex Mono  — technical: contact lines, specs, figures, code, captions.

All three are licensed under the SIL Open Font License 1.1 (see OFL-LICENSE.txt in
each folder). You may install, embed and redistribute them, including commercially.

Install
  macOS    select all .ttf files > right-click > Open > Install Font
  Windows  select all .ttf files > right-click > Install for all users
  Web      self-host, or load from Google Fonts:
           https://fonts.googleapis.com/css2?family=Manrope:wght@400;500;600;700&family=Inter:wght@400;500;600&family=IBM+Plex+Mono:wght@400;500&display=swap

Fallback stack, when the brand fonts are unavailable:
  display / text  'Segoe UI', 'Helvetica Neue', Arial, sans-serif
  mono            ui-monospace, SFMono-Regular, Menlo, Consolas, monospace
