SoniXense email signature
-------------------------
1. Open sonixense-email-signature.html in a browser.
2. Select all (Cmd/Ctrl-A), copy, paste into your mail client's signature box.
   Gmail: Settings > See all settings > Signature. Outlook: File > Options > Mail > Signatures.
3. To change the name block, edit the HTML in any text editor first.
The logo is embedded (base64) so it is not blocked as a remote image.
